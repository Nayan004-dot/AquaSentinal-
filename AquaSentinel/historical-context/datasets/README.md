# Dataset register
For each downloaded dataset, record publisher/title, official URL, source type, parameter category, geographic coverage, sampling period, download date/version, file name, units and caveats.

Candidate sources:
- CGWB groundwater-quality datasets: National Water Data Portal
- CPCB surface-water-quality datasets: National Water Data Portal

Inspect each resource's metadata and CSV headers. Do not assume all files have identical columns.
